# FV Exploration Radar (v2)

Self-hosted scout for new creative-content models & repos. Now with
**live search**, **persistent watchlist**, and a stub for future MCP
integration so Claude can run searches on your behalf.

## Two ways to run it

### Interactive (recommended) — `start.bat` or `python server.py`

Boots an HTTP server on **`http://127.0.0.1:8767`** and opens your browser.
You get:

- Search bar — free-text query across HF + GitHub, with optional source
  restrict and pipeline tag / GH topic filter
- One-click "📡 Trending" — re-runs the default scan (HF tags + GH topics
  curated for creative content)
- Tabs: **Results** + **Watchlist**
- Filter chips on Results: all / HF / GH / fresh ≤14d / recent ≤60d / saved
- ★ Save button on every card → persists to `watchlist.json`
- Star indicator on cards already in watchlist (works across both panes)

### One-shot static — `python scout.py`

Generates a self-contained `radar.html` (no server needed). Useful if you
want to email yourself a snapshot.

```bash
python scout.py            # full scan, opens browser
python scout.py --quick    # smaller per-tag limit (~10s vs ~30s)
python scout.py --quiet    # don't open browser, just write file
```

## API surface

The server exposes these endpoints — usable by curl, browser, or any tool:

| Endpoint | Method | Description |
|---|---|---|
| `/` | GET | serves `index.html` |
| `/api/health` | GET | `{ok, watchlist_size}` |
| `/api/trending?limit=12` | GET | run default tag/topic scan |
| `/api/search?q=...&source=hf\|gh\|both&tag=...&limit=25` | GET | live HF + GH search |
| `/api/watchlist` | GET | resolve current watchlist items |
| `/api/watchlist/add` | POST | body `{source, name}` |
| `/api/watchlist/remove` | POST | body `{source, name}` |

Examples:

```bash
curl 'http://127.0.0.1:8767/api/search?q=wan+gguf&source=hf&limit=10'
curl -X POST -H 'Content-Type: application/json' \
     -d '{"source":"HuggingFace","name":"black-forest-labs/FLUX.1-dev"}' \
     http://127.0.0.1:8767/api/watchlist/add
```

## Watchlist

- Stored in `watchlist.json` next to the script (gitignored).
- Seeded on first run with the FV reference set: Wan, FLUX, Cosmos, LTX,
  Higgs, ComfyUI, GPT-SoVITS, fish-speech, etc. See `WATCHLIST_SEED` in
  `scout.py`.
- Add via the ★ button in the UI, or via `POST /api/watchlist/add`.

## Rate limits

- HF API: no auth, generous (no token needed)
- GitHub anonymous: **60 req/h**. The default trending scan uses ~10
  topic queries + the watchlist resolution. You can run it a few times an
  hour comfortably; live search costs 1-2 reqs per query.
- For heavy use: `set GITHUB_TOKEN=ghp_xxxxx` (read-only token, no scopes
  needed) → 5000 req/h.

## Phase 2 — MCP

See `mcp-spec.md`. Short version: when you want Claude to be able to run
"find me i2v models released this month with GGUF quants and save the
top 3 to my watchlist" end-to-end, we wrap the same `scout.py` functions
as MCP tools. Not implemented yet because the current HTTP API already
covers manual exploration well.

## Cadence suggestion

- Personal habit: open `start.bat`, hit "📡 Trending" every 2-3 weeks
- Targeted exploration: when a topic catches your attention, type it into
  Search instead of relying on the curated tags
- Watchlist review: when one of your pinned models gets a recent activity
  bump (look at the days_ago field on the Watchlist tab) — that usually
  means a new release worth checking
