06 How to export to Instagram

3 formas, de más rápida a más profesional

  • Vía screenshot del browser (rápido, calidad limitada): abre este HTML, zoom 200%, screenshot del template, recorta exacto al cuadrado/vertical. Suficiente para 1080×1080.
  • Vía DevTools "Capture node screenshot" (calidad perfecta): F12 → click el elemento .tpl-quote en el inspector → 3 puntos → "Capture node screenshot" → exporta PNG exacto a las dimensiones reales.
  • Vía Figma / Canva (workflow profesional): si quieres que lo pase a Figma con cada layer editable separable, dime y te exporto los SVG individuales. Se importa con un drag.
