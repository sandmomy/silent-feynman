# About Section - Selected Design

## Archivo seleccionado: `about-particle-landing.html`

Este es el diseño elegido para integrar en la sección "About Me" del landing page principal.

### Características
- **Partículas Three.js** con geometría sagrada animada
- **3 secciones** con scroll interactivo:
  1. Introduction (Merkaba)
  2. The Work (Flor de la Vida)
  3. SBDI & Mission (Torus)
- **GSAP ScrollTrigger** para animaciones fluidas
- **Paneles 3D** con información del perfil

### Dependencias CDN
- Three.js r128
- GSAP 3.12.5 + ScrollTrigger
- Three.js Post-processing (EffectComposer, UnrealBloomPass)

### Assets requeridos
- `assets/meditation-bg.png` (fondo)
